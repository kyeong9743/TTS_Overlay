# voice 폴더

복제할 **목소리 파일**을 두는 곳입니다.

- 이 폴더에 `voice.opus`라는 이름으로 넣으면 별도 설정 없이 기본 목소리로 사용됩니다.
- 사용할 수 있는 형식: `.wav`, `.flac`, `.ogg`, `.opus`, `.mp3`, `.m4a`
- 길이는 3초 이상이어야 하고, 15초를 넘으면 앞 15초만 쓰입니다(설정에서 구간 지정 가능).
- 다른 이름이나 다른 위치의 파일을 쓰려면 설정의 "목소리 오디오 파일"에서 찾아보기로 지정하세요.

본인 목소리 또는 명시적으로 동의를 받은 목소리만 사용하세요.
